# Rex 虎牙直播模块

面向 Rex 播放器的虎牙直播模块，用于在 Rex 中发现、搜索和播放虎牙直播内容。

模块以直播使用场景为核心，整合分类导航、主播与房间搜索、开播状态识别、直播详情以及多画质、多线路播放能力。

> 作者：`ukonic`
>
> 项目性质：非官方模块

## 快速导入

推荐使用下面的固定地址：

```text
https://raw.githubusercontent.com/ukonic/Rex-HuyaLive/main/Rex-Huya-Live.js
```

在 Rex 的模块管理或远程导入界面中粘贴该地址即可。

固定地址始终指向仓库中的当前版本。请勿使用 GitHub 仓库首页或带 `/blob/` 的文件页面地址，它们返回的是网页而不是模块源码。

## 模块定位

本模块主要解决以下需求：

- 在 Rex 首页或模块页面浏览虎牙当前正在直播的内容
- 按游戏、娱乐类型或分类名称查找直播间
- 按关键词、主播名、房间号或虎牙房间链接搜索
- 区分正在直播、暂未开播、回放和异常房间
- 在播放时实时生成虎牙 HLS 地址，并提供多画质和多 CDN 线路

它不是虎牙客户端的完整替代品，重点是直播内容的发现、状态判断和播放接入。

## 功能范围

### 内容浏览

- 推荐直播列表，支持分页加载
- 热门分类快捷入口
- 网游竞技、单机游戏、手机游戏和娱乐生活分区
- 按中文名称查找虎牙分类
- 支持自定义虎牙游戏 ID

### 搜索与房间

- 按关键词或主播名搜索直播
- 可选填写房间号，直接查找指定直播间
- 支持输入完整虎牙房间链接
- 可选择在搜索结果中显示未开播主播
- 未开播主播只出现在搜索结果末尾，不会混入推荐、分类或相关直播列表

### 状态与详情

- 打开房间详情时重新检查直播状态
- 区分直播、未开播、回放、房间不存在和线路暂不可用
- 首页指定房间未开播时返回空结果，避免显示无法播放的卡片
- 展示直播标题、主播、房间号、分类、画质和可用线路等信息

### 直播播放

- 起播时实时获取播放数据，不保存固定直播地址
- 动态生成虎牙 HLS 播放签名
- 提供多画质选择
- 优先提供不同 CDN 的多条线路
- 单条线路异常时保留其他可用线路，并在必要时自动重试

## Rex 模块入口

| 入口 | 用途 |
| --- | --- |
| 虎牙推荐直播 | 浏览当前推荐直播 |
| 虎牙热门分类 | 快速选择常用游戏和娱乐分类 |
| 网游竞技 | 电脑网游与电竞直播 |
| 单机游戏 | 单机、主机、沙盒与生存游戏直播 |
| 手机游戏 | 热门手游与休闲手游直播 |
| 娱乐生活 | 户外、才艺、体育、一起看等内容 |
| 按名称查找分类 | 不知道游戏 ID 时按中文名称查询 |
| 指定虎牙房间 | 输入房间号或完整虎牙房间链接 |
| 自定义游戏 ID | 使用虎牙分类网址 `/g/` 后的数字 |

## 使用说明

### 房间号

虎牙房间地址通常类似：

```text
https://www.huya.com/1995
```

其中 `1995` 就是可以填写到“指定虎牙房间”或搜索参数中的房间号。

### 游戏 ID

虎牙分类地址通常类似：

```text
https://www.huya.com/g/2135
```

其中 `2135` 是虎牙游戏 ID，可用于“自定义游戏 ID”入口。

### 未开播与回放

- 未开播主播可以通过搜索显示，但不会作为可播放直播混入直播列表。
- 回放会被识别为非直播内容，当前模块不会为其生成直播播放资源。
- 主播重新开播后，再次进入详情会重新检查状态并获取新的播放线路。

## 当前限制

- 当前只接入虎牙直播，不提供房间回放播放。
- 当前未接入虎牙弹幕。
- 模块依赖虎牙公开接口和网页直播数据结构，上游接口或页面结构变化时可能需要适配。
- 房间没有有效 HLS 线路，或所有线路签名均生成失败时，无法提供播放资源。
- 实际功能和界面表现可能受 Rex 客户端版本影响。
